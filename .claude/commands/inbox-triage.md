複数の Gmail アカウントを横断して、いま返信が必要そうなメールをトリアージしてください。

手順:
1. 接続済み Gmail MCP で利用可能なアカウントを列挙する。
2. 各アカウントの直近48時間の受信メール（未読 / 相手のボールになっているスレッド）を取得する。
3. 次の軸で「要返信」を判定する:
   - 自分宛(To) か CC のみか
   - 質問・依頼・承認待ち・締切が含まれるか
   - 重要送信者か（木山 / iroribi / Muzammal / m3logi / 武田 / グッドリース / 茅ヶ崎 など。適宜編集）
   - スレッドで相手の発言が最後か
4. ニュースレター / 自動通知 / no-reply は除外。

出力（JSON ではなく、読みやすいテキストで）:
- 🔴 優先 / 🟡 通常 に分けて、[アカウント] 件名 / 送信者 / 一言理由 / リンク を一覧。
- 最後に「下書きを作りますか？」と聞く。作る場合は **下書きまで**（送信はしない）。
