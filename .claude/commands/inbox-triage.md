複数の Gmail アカウントを横断して、いま確認・対応が必要そうな受信メールをトリアージしてください。
※ 読み取りのみ。送信・下書き・返信・既読化・削除はしません。

手順:
1. 接続済み Gmail MCP（読み取り専用）で利用可能なアカウントを列挙する。
2. 各アカウントの直近48時間の受信メール（未読 / 相手のボールになっているスレッド）を取得する。
3. 次の軸で「要対応」を判定する:
   - 自分宛(To) か CC のみか
   - 質問・依頼・承認待ち・締切が含まれるか
   - スレッドで相手の発言が最後か
4. 除外リスト（★編集可・部分一致）に該当するものは除外:
   - ニュースレター / プロモ / 自動通知 / システム通知 / カレンダー通知
   - no-reply, newsletter, notification, alert などの送信者・ドメイン・件名キーワード
   - （ここに無視したい送信者・ドメイン・キーワードを追記）

出力（読みやすいテキスト）:
- 🔴 優先 / 🟡 通常 に分けて、[アカウント] 件名 / 送信者 / 一言理由 / リンク を一覧。
- 要対応の新規メールが無ければ「要対応の新規メールはありません」とだけ伝える。
